# Build 서브에이전트 지침

먼저 `CLAUDE.md`와 `worlds/{slug}/plan.md`를 읽는다. `review.md`가 있으면 그것도 읽고, 지적된 문제부터 고친다.

## 만들 파일
```
worlds/{slug}/
  index.html   # 구조. 입장 화면 + 장면들
  style.css    # 색은 :root CSS 변수로 정의한다
  world.js     # 상호작용, 장면 전환, 오디오
  assets/      # 사용자 제공 이미지·소리 (있을 때만)
```

## 필수 구현
1. **입장 화면:** 세계 이름, "WORLD #번호", "탭해서 입장" 버튼. 이 버튼을 누를 때 `AudioContext`를 생성하거나 resume한다. 모바일 자동재생 제한 때문이다.
2. **소리 버튼:** 화면 구석에 항상 보이게 둔다. 음소거 상태는 localStorage에 기억하되, try/catch로 감싼다.
3. **plan.md의 모든 클릭 요소:** 각 요소마다 시각 반응과 소리 반응을 구현한다. 터치 영역은 최소 44×44px이다.
4. **장면 전환:** 부드러운 전환(페이드 등)을 쓴다. 뒤로 가기 방법도 둔다.
5. **숨겨진 요소:** plan대로 구현하되, 화면에 힌트를 직접 쓰지 않는다.
6. **모바일 우선:** 375×812 세로 화면 기준으로 설계하고, 가로 스크롤이 없어야 한다. `<meta name="viewport">`를 넣는다. PC에서도 깨지지 않게 한다.
7. **성능:** 첫 화면은 가볍게 만든다. 애니메이션은 transform/opacity 위주로 쓰고, Canvas는 requestAnimationFrame을 쓰며 탭이 숨겨지면 멈춘다.
8. `prefers-reduced-motion`을 존중한다.

## 금지
- 프레임워크, 빌드 도구, npm 사용
- 출처 불명 외부 이미지·소리 다운로드
- `worlds/{slug}/` 밖의 파일 수정

## 반환
메인에게는 **만든 파일 목록**, **plan과 다르게 구현한 점(있으면)**, **열어보는 방법**만 짧게 돌려준다. 코드 전문은 붙이지 않는다.
