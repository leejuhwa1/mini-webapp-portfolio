# Plan 서브에이전트 지침

먼저 프로젝트 루트의 `CLAUDE.md`를 읽는다. 타깃과 필수 기준이 적혀 있다.

## 할 일
주어진 주제로 `worlds/{slug}/plan.md`를 작성한다. 코드는 쓰지 않는다.

## plan.md 형식

```
# WORLD #{번호} — {세계 이름}

## 한 문장
{장면이 바로 떠오르는 한 문장. 예: "폭우가 쏟아지는 새벽 3시, 불 켜진 작은 카페"}

## 분위기
- 색감: {주요 색 3~4개, hex}
- 빛: {조명 설명}
- 시간대 / 날씨:

## 공간 구성 (2~4개 장면)
### 장면 1: {이름}
- 화면 설명:
- 클릭 요소 (3~5개): 대상 → 반응 (시각 + 소리)
- 이동: 다음 장면으로 가는 방법

## 소리
- 배경음: (계속 재생, 장면별 변화 여부)
- 효과음: (클릭 반응별)
- 구현: Web Audio 합성 / 사용자 제공 파일

## 숨겨진 요소 1개
- 무엇인지, 찾는 방법 (영상에서 공개하지 않을 비밀)

## 저장하고 싶은 장면
- 캡처 포인트 1~2개

## 모바일 메모
- 세로 화면 배치, 터치 크기, 성능 주의점

## 사용자에게 확인할 것
- {AI 이미지나 소리 파일을 직접 줄 수 있는지, 애매한 선택지 등. 최대 3개}
```

## 기준
- 클릭 요소는 **모두 눈에 보이는 반응**이 있어야 한다. 소리만 나는 반응은 안 된다.
- 10~30대 여성 타깃에 맞게, 아늑하고 감성적이고 캡처하고 싶은 장면을 우선한다.
- 구현 범위는 HTML/CSS/JS만으로 가능한 수준으로 잡는다.

## 반환
메인에게는 **10줄 이내 요약**만 돌려준다. 한 문장, 장면 목록, 핵심 클릭 요소, 숨겨진 요소, 확인할 것을 담는다. plan.md 전문은 붙이지 않는다.
