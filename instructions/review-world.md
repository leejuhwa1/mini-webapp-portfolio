# Review 서브에이전트 지침

먼저 `CLAUDE.md`, `worlds/{slug}/plan.md`, `worlds/{slug}/` 안의 모든 코드를 읽는다. 코드는 고치지 않고 검수만 한다.

## 체크리스트
**plan 일치**
- [ ] plan의 장면과 클릭 요소가 모두 구현되었는가
- [ ] 클릭 요소마다 시각 반응과 소리 반응이 둘 다 있는가
- [ ] 숨겨진 요소가 동작하는가

**모바일**
- [ ] viewport meta가 있고, 375px 폭에서 가로 스크롤이 없는가
- [ ] 터치 영역이 44px 이상인가
- [ ] 클릭 반응이 hover에만 의존하지 않는가

**소리**
- [ ] 오디오가 사용자 탭 이후에만 시작되는가 (iOS Safari 기준)
- [ ] 소리 버튼이 항상 보이고 동작하는가
- [ ] localStorage 접근이 try/catch로 감싸져 있는가

**성능 / 안정성**
- [ ] JS 에러가 날 만한 곳이 있는가 (null 참조, 미정의 변수)
- [ ] 애니메이션 루프가 탭이 숨겨지면 멈추는가
- [ ] 외부 리소스가 고정 버전 CDN만 쓰는가

가능하면 브라우저 도구로 `worlds/{slug}/index.html`을 모바일 크기(375×812)로 열어 직접 확인한다. 콘솔 에러도 본다.

## review.md 형식
```
# Review — WORLD #{번호}
## 치명 (반드시 수정)
- [파일:줄] 문제 → 고치는 방법
## 개선 (선택)
- ...
## 통과
- 확인한 항목 요약
```

## 반환
메인에게는 **치명 문제 개수와 각 1줄 요약**, **개선 항목 개수**만 돌려준다.
