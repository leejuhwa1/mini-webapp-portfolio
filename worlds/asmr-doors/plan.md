# WORLD #001 — ASMR 세계 (`asmr-doors`)

> 잔디밭 한가운데 서 있는 문 하나. 열고 들어가면, 소리로 가득한 여섯 개의 방.

- 주제: ASMR 세계 (사용자 지정)
- slug: `asmr-doors`
- 타깃: 10~30대 여성, 유튜브 고정 댓글 링크 → 폰 세로 화면(375px)으로 입장
- 기술: HTML/CSS/JS만. 빌드 도구·프레임워크·외부 서버 없음. 외부 라이브러리는 버전 고정 CDN만 (**Three.js 0.160.0**).
- 폴더: `worlds/asmr-doors/` → `index.html`, `style.css`, `world.js`, `js/`(모듈), `assets/sounds/`(기존 녹음 26개, 420KB), `assets/textures/`(CC0 질감)

## ★ 0. 3D 전환 (2026-11-07 사용자 결정 — 이 장이 아래 모든 2D 묘사보다 우선)

사용자 결정: **실사풍 3D + 1인칭 시점.** 아래 2~3장, 7장, 9장, 10장에 적힌 2D 구현 방법(CSS 그라디언트 하늘, Canvas 풀잎, 옆에서 보는 횡스크롤, 3인칭 캐릭터, 고정 화면 방)은 **이 장으로 대체된다.** 장면 흐름, 색감, 방별 물건·소리, 발소리·문 소리(5-1), 배경음, 숨겨진 요소, 소리 버튼 규칙은 그대로 유효하다.

### 0-1. 엔진과 로딩
- **Three.js 0.160.0**을 `cdn.jsdelivr.net/npm/three@0.160.0/` import map으로 쓴다(`three`, `three/addons/`). 다른 라이브러리는 쓰지 않는다.
- **첫 화면에서는 Three.js를 불러오지 않는다.** 첫 화면 = `index.html` + `style.css` + 아주 작은 진입 스크립트(+ CSS로 그린 하늘·잔디 배경 그림). "탭해서 입장" 순간 오디오 시작 + `import()`로 엔진과 잔디밭 질감 로드 → "세계를 여는 중 37%" 진행 바 → 잔디밭.
- 장면별 지연 로드: 잔디밭 질감은 입장 시, 복도 질감은 잔디밭 문 앞에 섰을 때 프리페치, 방 질감·소리는 복도에서 그 문 앞에 섰을 때 프리페치. 한 번에 보이는 장면은 하나, 안 쓰는 장면은 렌더 루프에서 빠진다.
- WebGL이 안 되는 기기: "이 기기에선 3D가 열리지 않아요" 안내 + 소리만 들을 수 있는 간단한 방 목록(버튼) 대체 화면.

### 0-2. 실사풍 그래픽 원칙
- 렌더러: `ACESFilmicToneMapping`, sRGB 출력, `MeshStandardMaterial`/`MeshPhysicalMaterial` PBR. 부드러운 그림자(directional light 1개만 그림자, PCFSoft, 모바일 512 / PC 1024~2048). 원거리 `Fog`로 깊이감.
- 하늘: `three/addons/objects/Sky.js`(물리 기반 하늘) + 같은 하늘로 만든 환경맵(`PMREMGenerator`)으로 물체에 자연스러운 반사광. 구름은 부드러운 반투명 구름 스프라이트 여러 장이 천천히 흐름.
- **질감(텍스처)은 Poly Haven(polyhaven.com, 전부 CC0)에서만** 받는다. 1k 해상도 JPG, 필요한 맵만(diffuse + normal + roughness, 가능하면 ARM 합본). 받은 파일은 `assets/textures/`에 두고 `assets/textures/CREDITS.md`에 자산 이름·원본 URL·라이선스(CC0)를 적는다. 출처가 불분명한 파일은 받지 않는다.
  - 용량 예산: 질감 전체 **6MB 이하**, 장면 하나 **2MB 이하**. 방마다 질감은 2~3종으로 아껴 쓰고, 나머지는 색·러프니스만으로 표현.
  - 필요하면 Poly Haven CC0 3D 모델(glTF)도 쓸 수 있다(파일 하나 1.5MB 이하, 꼭 필요한 것만, CREDITS에 기록). 기본은 코드로 만든 형태(Box/Cylinder/Lathe 등)에 실사 질감을 입힌다.
- 문: 코드로 만든 패널 문(문틀 + 6판 패널 + 금색 손잡이) + 페인트 나무 질감. 경첩 기준으로 실제로 회전하며 열린다.
- 문 열림 빛: 문 안쪽에 밝은 발광 면 + 가짜 볼륨 광(가산 혼합 반투명 원뿔/평면) + 화면 전체 흰빛·금빛 페이드. 무거운 후처리(블룸 등)는 PC에서만 켜고 모바일은 끈다.

### 0-3. 장면별 3D 구성
- **잔디밭:** 넓은 들판(지평선까지), 잔디 질감 바닥 + `InstancedMesh` 풀잎(셰이더로 바람에 흔들림, 카메라 주변에 밀집·멀리는 질감만; 모바일 약 8천~1.5만 / PC 3만+). 멀리 완만한 언덕. 한가운데 민트색 문이 홀로 서 있고 시작 위치는 문에서 약 12m 앞. 문 뒤편에 네잎클로버(숨겨진 요소 ②).
- **햇살 복도 → "햇살 홀"로 변경:** 문을 열고 들어서면 **정면 벽에 문 6개가 부드러운 곡선으로 나란히** 보이는 넓은 홀(참고 사진 2번의 "앞에 문들이 늘어선" 구도, 단 밝게). 크림·버터 옐로 벽 + 피치 웨인스코팅 + 꿀색 원목 마루 + 로즈 베이지 러그, 천장 펜던트 조명, 옆벽 높은 창으로 햇살 줄기(가산 반투명 빔) + 떠다니는 먼지 반짝이. 문 6개는 방 테마 파스텔 색, 문틈·문 아래로 금빛이 새어 나와 바닥에 번짐. 등 뒤에는 들어온 민트색 문(밖으로). 홀 한쪽 구석에 작은 일곱 번째 문(숨겨진 요소 ①).
- **방 6개:** 각각 작은 3D 방(약 4×4m). 들어서면 방 가운데에 서서 둘러볼 수 있고, 좁은 범위에서 걸을 수도 있다. 물건은 손 닿는 높이(탁자·선반 위)에 모여 있어서 처음 서 있는 자리에서 대부분 보인다. 물건마다 3D 애니메이션(눌림·늘어남·잘림·흔들림·파티클)은 4장 내용 그대로.

### 0-4. 1인칭 조작
| 상황 | PC | 모바일 |
|---|---|---|
| 걷기 | WASD/방향키 | 화면 왼쪽 절반 플로팅 조이스틱 |
| 둘러보기 | 마우스 드래그 (포인터 잠금 안 씀 → 클릭으로 물건 누르기 가능) | 화면 오른쪽 절반 드래그 |
| 물건 누르기 | 클릭 (레이캐스트) | 탭 (짧게 탭 = 누르기, 드래그 = 둘러보기) |
| 문 열기 | 문 앞에서 `E`/`Enter`/'들어가기' 또는 문 클릭 | '들어가기' 버튼 또는 문 탭 |
| 방 → 홀 | '← 홀로' 버튼 / `Esc` | '← 홀로' 버튼 |
- 문이나 물건을 탭하면 그쪽으로 자동으로 걸어가며 바라본다(조작이 어려운 사람용).
- 걸을 때 머리가 아주 살짝 위아래로 흔들리고(멀미 안 나게 약하게), **발소리는 그 흔들림의 아래 지점에 맞춰** 난다(5-1).
- 시선 상하 각도 제한(-60°~+60°), 벽·가구 충돌(간단한 원/사각 충돌).
- 누를 수 있는 물건은 화면 가운데 근처에 오면 은은한 빛 테두리 + "탭!" 힌트.

### 0-5. 성능 (폰 기준)
- pixelRatio = min(devicePixelRatio, 모바일 1.5 / PC 2). 실제 FPS를 재서 40fps 미만이 이어지면 풀잎 수·그림자·pixelRatio를 자동으로 낮춘다.
- 실시간 그림자를 만드는 빛은 1개. 실내는 환경광 + 발광 재질 + 점광원 최대 3개.
- 장면 전환 시 이전 방의 지오메트리·질감은 `dispose()` (홀과 잔디밭은 캐시 유지).

### 0-6. 파일 구성 (3D)
```
worlds/asmr-doors/
├─ index.html      # 입장 화면 + 공통 UI(소리 버튼, 조이스틱, 들어가기/홀로 버튼, 로딩 바) + import map
├─ style.css       # 입장 화면 그림(CSS), UI 스타일
├─ world.js        # 진입: 탭해서 입장 → 오디오 시작 → 엔진 동적 import
├─ js/             # engine.js(렌더러·루프·품질), controls.js(1인칭), audio.js(녹음 로더 + 합성), meadow.js, hall.js, rooms.js(방 6개 데이터 + 생성), doors.js
├─ assets/sounds/  # 기존 녹음 26개 (수정 금지)
└─ assets/textures/ # Poly Haven CC0 1k 질감 + CREDITS.md
```
- 이전에 만들다 멈춘 2D 버전 파일(`index.html`, `style.css`, `world.js`, `audio.js`, `rooms.js`)은 3D 버전으로 교체한다. `audio.js`의 합성 소리 코드가 쓸 만하면 `js/audio.js`로 옮겨 재사용해도 된다.

## 1. 전체 흐름

```
[입장 화면] "탭해서 입장" ──탭──▶ [1. 잔디밭] ──문 앞에서 '들어가기'──▶ [2. 햇살 복도]
                                                                   │
                                     ◀── '복도로 돌아가기' ──  [3. 테마 방 ×6]  ◀── 문 앞에서 '들어가기'
```

- 장면은 3단계: **잔디밭 → 복도 → 방**. 한 페이지(index.html) 안에서 장면을 전환한다(페이지 이동 없음).
- 전환 연출: 문이 열리며 안쪽 빛이 화면을 채움 → 페이드(약 0.6초). 소리도 함께 크로스페이드. **문 여는 소리 → 빛 → 장면 전환**이 한 흐름으로 이어지게 타이밍을 맞춘다(아래 5-1 참고).
- 복도에서 잔디밭으로 돌아가는 길: 복도 맨 끝(시작 지점 뒤)에 들어온 문이 있고, 그 앞에서 '밖으로' 버튼.

## 2. 공간 구성

### 0) 입장 화면 (첫 화면, 3초 안에)
- 잔디밭 장면을 CSS 그라디언트만으로 흐릿하게 미리 보여주고, 가운데 **"탭해서 입장"** 버튼과 제목 `WORLD #001 · ASMR DOORS`.
- 안내 한 줄: "🎧 이어폰을 끼면 더 좋아요".
- 이 시점엔 오디오 파일을 하나도 불러오지 않는다. 탭 순간 `AudioContext` 생성·resume → 잔디밭 배경음 시작.

### 1) 잔디밭 (Scene: meadow)
- **분위기 참고:** 사용자가 보낸 사진(영화 '스즈메의 문단속' 장면)의 *느낌*만 참고한다 — 탁 트인 초록 들판, 맑고 진한 파란 하늘, 그 한가운데 덩그러니 서 있는 문 하나의 낯섦. **원작의 그림, 캐릭터, 구도, 문 디자인은 따라 하지 않는다.**
- 직접 그리기:
  - 하늘: CSS 세로 그라디언트(진한 하늘색 → 지평선 근처 연한 하늘색). 뭉게구름 2~3개는 SVG/CSS 원 겹치기, 천천히 옆으로 흐름.
  - 잔디: 지평선 아래 초록 그라디언트 + Canvas로 풀잎 수백 개를 그려 바람에 살랑(사인파 흔들림). 모바일 성능 위해 풀잎 수는 화면 크기에 따라 조절.
  - 문: 이 세계 고유 디자인 — 크림색 문틀 + 연한 민트색 나무 문, 동그란 금색 손잡이. 문 뒤엔 아무것도 없음(뒤로 돌아가면 그냥 들판). 문틈으로 아주 약한 빛.
- 시점: **3인칭 옆/뒤 시점의 작은 캐릭터**가 잔디 위를 걷는다(아래 '조작' 참고). 원근감: 캐릭터가 문 쪽(위쪽)으로 갈수록 작아짐. 문은 화면 위쪽 중앙 멀리 있다가 다가가면 커진다.
- 캐릭터: 원작 캐릭터를 닮지 않은 단순한 실루엣(동그란 머리 + 원피스/코트 형태, 파스텔). CSS/SVG로 그림. 걸을 때 위아래 통통.
- 문 근처(반경 안)에 오면 문이 살짝 빛나고 **'들어가기'** 버튼 등장.

### 2) 햇살 복도 (Scene: hallway)
- **분위기 참고 사진:** 살짝 열린 문들에서 따뜻한 빛이 새어 나오는 구도만 참고한다. **사진처럼 어둡게 만들지 않는다 (사용자 요청: 어두우면 안 됨).**
- **색감: 밝고 포근한 "늦은 오후 햇살" 복도.** 동화 속 아늑한 집 복도처럼 밝은 파스텔 톤.
  - 벽: 크림~버터 옐로(`#FFF3DC` → `#FBE7C6` 세로 그라디언트) + 아주 연한 세로 줄무늬 벽지. 아래쪽 1/3은 연한 피치/코랄 웨인스코팅(`#F6CDB8`)과 흰색 몰딩 한 줄.
  - 천장: 따뜻한 흰색, 작은 펜던트 조명 몇 개가 부드럽게 빛남(은은한 원형 글로우).
  - 바닥: 밝은 꿀색 원목 마루(`#E9C49A` 계열, 나뭇결 줄무늬) 위에 로즈 베이지 러너 카펫(`#E8B4A8`).
  - 창: 문 사이사이에 작은 창 2~3개, 바깥 하늘(잔디밭과 같은 파랑)이 보이고 바닥에 사선 햇살 무늬가 떨어짐. 먼지 반짝이 파티클 몇 개가 천천히 떠다님.
- 구성: 가로로 긴 복도를 **옆에서 보는 횡스크롤** 장면. 화면 폭보다 넓고 캐릭터 이동에 따라 카메라가 따라감.
  - **문 6개가 일정 간격으로 나란히.** 각 문은 방 테마 파스텔 색(슬라임=라벤더, 다꾸=연두, 카페=딸기우유 핑크, 다락방=하늘색, 캠핑=세이지 그린, 바닷속=민트블루). 살짝 열려 있고 문틈과 문 아래로 **황금빛 빛**이 새어 나와 바닥에 번짐. 밝은 배경에서도 보이도록 빛은 진한 골드(`#FFC94D`) 글로우 + 느린 반짝임.
  - 문마다 작은 명패(이모지 + 방 이름). 문 색은 방 테마에 맞게 살짝 다름.
  - 왼쪽 끝: 잔디밭에서 들어온 민트색 문(밖으로 나가기).
  - 오른쪽 끝: 숨겨진 요소 ① (아래 참고).
- 캐릭터가 문 앞에 서면 그 문의 빛이 밝아지고 '들어가기 · 🫧 슬라임 공방' 처럼 방 이름이 같이 뜸.

### 3) 테마 방 ×6 (Scene: room)
- 방은 **고정 화면(이동 없음)**, 세로 375px 기준 한 화면에 물건이 다 보이게 배치. 물건은 손가락으로 누르기 편하게 최소 64×64px.
- 상단 왼쪽: **'← 복도로'** 버튼. 상단 오른쪽: 소리 버튼(항상 보임).
- 방 입장 시 그 방의 녹음 파일만 로드 → 로딩 중엔 물건이 반투명 + "소리 준비 중…" 작게 표시(보통 1초 이내).
- 공통 반응: 물건 탭 → 눌림 애니메이션(스쿼시/흔들림) + 작은 파티클 + 소리. 같은 물건 연타 가능(소리 겹쳐서 재생, 최대 동시 6개 제한).

### 5-1. 발소리와 문 소리 (사용자 요청, Web Audio 합성)
**발소리** — 캐릭터가 움직이는 동안만, 걷기 애니메이션의 발 디딤(통통 튀는 아래 지점)에 정확히 맞춰 한 걸음씩 재생. 멈추면 바로 끊김.
| 장면 | 발소리 느낌 | 합성 방법 |
|---|---|---|
| 잔디밭 | 풀 밟는 '사박, 사박' | 짧은 밴드패스 노이즈(2~5kHz, 80~120ms) + 아주 약한 저역 '툭'. 걸음마다 필터 주파수·볼륨·길이 랜덤(±15%), 왼발/오른발 살짝 다른 톤 |
| 복도 | 카펫/마루 위 '톡, 톡' 부드러운 실내 발소리 | 로우패스 노이즈 버스트(600~1200Hz, 60~90ms) + 저음 사인 '퉁'(90~120Hz, 짧게). 카펫 구간은 더 부드럽고, 마루 구간은 살짝 또렷하게 |
- 걸음 간격 약 0.35~0.4초(이동 속도에 비례). 볼륨은 배경음보다 살짝 크게, 물건 소리보다는 작게.
- 자동 이동(문 탭)할 때도 똑같이 발소리 남.

**문 소리** — '들어가기'를 누르면 아래 순서가 끊김 없이 이어진다 (총 약 1.2초).
1. 손잡이 돌림 '딸깍' (0초): 짧은 금속 클릭 두 개(고음 사인 + 노이즈 틱, 30ms 간격)
2. 문 열림 '끼이익' (0.15초~0.9초): 오래된 나무 경첩 삐걱. 톱니파를 밴드패스로 걸러 피치를 천천히 흔들며(300→550Hz 불규칙 글라이드) + 나무 마찰 노이즈. 너무 날카롭지 않게 부드럽고 짧게, 할 때마다 피치·길이 살짝 랜덤.
3. 빛이 쏟아지며 '스으' (0.5초~): 부드러운 바람/에어 노이즈 스웰 + 들어갈 장면의 배경음이 문틈에서 커지며 크로스페이드.
- 방에서 '← 복도로' 나올 때: 문 닫힘 '탁'(저음 나무 노크 + 짧은 걸쇠 클릭)을 작게.
- 잔디밭 첫 문, 복도 6개 문, 숨겨진 7번째 문 모두 같은 방식. 문마다 피치를 조금 다르게 해서 개성 부여(일곱 번째 문은 맑은 종소리 한 번 추가).
- 화면 연출과 소리 타이밍을 맞춘다: 문 그림이 실제로 열리는 애니메이션(0.15~0.9초)과 '끼이익'이 동시에.

- 장면 전환 시 1초 크로스페이드. 배경음은 물건 소리보다 충분히 작게(마스터 대비 약 30%).
- 노이즈 버퍼는 한 번 만들어 재사용(화이트/핑크/브라운 2초 버퍼 루프).
- 탭에서 벗어나면(`visibilitychange`) 소리 일시정지, 돌아오면 재개.

## 6. 소리 버튼과 오디오 규칙
- **"탭해서 입장"** 버튼 탭으로만 `AudioContext` 시작 (iOS/안드로이드 자동재생 정책).
- **🔊/🔇 버튼은 모든 장면에서 항상 오른쪽 위 고정.** 끄면 마스터 게인 0, 상태는 `localStorage`에 기억(try/catch).
- 녹음 파일은 `fetch` → `decodeAudioData`로 AudioBuffer 캐시. 한 번 받은 방은 다시 들어갈 때 바로 재생.

## 7. 로딩 전략 (첫 화면 3초)
- 첫 화면: `index.html` + `style.css` + `world.js`만. 이미지 파일 없음(전부 CSS/SVG/Canvas). 녹음 파일 0개.
- 잔디밭 Canvas 풀잎은 입장 후 그리기 시작.
- 방 입장 시 **그 방 소리만** 로드:
  - 슬라임 공방: slime-press 5 + slime-stretch 2 + sand-cut 7 + bubble-pop 6 = 20개 (약 295KB)
  - 다꾸 책상: tape-tear 2 + pencil 3 + paper-flip 1 = 6개 (약 116KB)
  - 나머지 4개 방: 파일 없음(합성)
- 추가 최적화: 복도에서 슬라임/다꾸 문 앞에 서는 순간 미리 로드 시작(프리페치).
- 로드 실패 시: 해당 물건은 애니메이션만 동작, 콘솔 경고만 남기고 멈추지 않음.

## 8. 숨겨진 요소 (제안 2개)
1. **복도 끝 일곱 번째 문 (오른쪽 끝, 아주 작고 빛 없는 문)**
   - 6개 방에서 물건을 각각 한 번 이상 눌러 보면(방문 기록), 복도 끝 작은 문 틈으로 빛이 켜진다. 들어가면 별빛이 도는 작은 방에서 **6개 방의 배경음이 아주 작게 하나로 섞인 '자장가 믹스'** 가 흐르고 "오늘도 수고했어요" 문구. 진행 상태는 `localStorage`(실패해도 그냥 숨김 유지).
2. **잔디밭의 문 뒤로 돌아가기**
   - 문 앞이 아니라 **문 뒤편**으로 걸어가면 들판에 작은 네잎클로버가 하나 있다. 탭하면 바람이 한 번 크게 불고(풀이 일제히 눕는 애니메이션 + 바람 소리 스웰) 하늘에 잠깐 무지개가 뜬다.

## 9. 레이아웃·접근성
- 375×667 기준 설계, 큰 화면은 가운데 정렬 + 배경 확장. 가로 스크롤 없음.
- 버튼 최소 44px, 주요 버튼(들어가기, 복도로)은 56px 이상, 엄지 닿는 아래쪽 배치(복도로 버튼은 위 왼쪽 + 방 안 아래에도 하나).
- `touch-action: none`(조이스틱 영역), 더블탭 확대 방지, `user-select: none`.
- `prefers-reduced-motion`이면 파티클·흔들림 줄임.
- 글꼴: 시스템 글꼴(외부 폰트 로드 없음, 3초 기준 지키기).

## 10. 파일 구성 (Build 단계 산출물)
```
worlds/asmr-doors/
├─ index.html     # 장면 컨테이너(입장/잔디밭/복도/방), 공통 UI(소리 버튼, 조이스틱, 들어가기 버튼)
├─ style.css      # 장면별 그림(CSS/SVG), 애니메이션, 모바일 레이아웃
├─ world.js       # 장면 전환, 이동/조이스틱, 충돌·문 감지, 오디오 엔진(로더+합성), 방 데이터
├─ plan.md        # 이 문서
└─ assets/sounds/ # 기존 녹음 26개 (수정하지 않음)
```
- `world.js` 안에 방 데이터를 표(배열)로 둔다: `{id, emoji, name, files:[...], objects:[{id, label, sound}], ambience}` → 방 추가/수정이 쉽게.
